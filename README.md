Sales & Revenue Analysis Dashboard

Overview:
This project is an interactive Excel dashboard created to analyze sales and revenue performance across different categories and regions.

The dashboard provides insights into:
- Total Sales
- Total Orders
- Average Sales
- Sales by Category
- Regional Sales Distribution

Dashboard Features
- Interactive slicers for:
  - Region
  - Category
- KPI Cards
- Bar Charts
- Pie Charts
- Trend Analysis

Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning & Formatting

Files Included
- Dashboard.xlsx
- Sales_Data.xlsx
